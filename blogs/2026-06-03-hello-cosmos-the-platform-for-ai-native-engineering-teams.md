Augment Code announces Cosmos, an operating system that coordinates agents and developers across the entire software development lifecycle. Rather than isolated code generation, the platform enables specialized agents to work collaboratively on tasks like triage, review, testing, and deployment while maintaining shared memory and context. Teams can customize Cosmos with their existing tools and workflows, with the system itself capable of being extended through natural language descriptions of desired automations.
